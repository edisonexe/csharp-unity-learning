# Практика по Модулю 4. Продвинутый C#. Часть 1

## 🎮 Задание 1

### 📋 Логи и UI:

* Кнопка **Показать логи** - открывает ScrollView с историей событий
* Кнопки-фильтры:
  * **Все** - полный список событий
  * **Битва началась** - события данного типа
  * **Враг создан** - события данного типа
  * **Кол-во поднятых предметов**
  * **Последние 10 событий**
  * **Топ 3**

### ⚙️ Автогенерация:

* **AutoEventGenerator** создаёт случайные события
* Подписчики реагируют на них:
  * **NPC** - идут к врагу
  * **EnemyManager** - создаёт врагов в случайных точках
  * **WeatherManager** - меняет погоду (цвет фона камеры)
