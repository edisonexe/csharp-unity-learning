# Практика по Модулю 3. Core Unity

## 🎮 Задание 1

### 🎯 Цель

* Представляет собой куб
* Появляется в случайной точке на экране в зоне видимости
* Живёт 3 секунды, после чего уничтожается
* В консоль выводятся логи жизненного цикла
*  Дополнительное поведение - ращение и плавный скейл (от 1 до 2 и обратно)

### ⚙️ GameManager

* Каждые 4 секунды создаёт новую цель
* Использует InvokeRepeating()
* Спавн начинается сразу после загрузки игровой сцены

### 🔄 **Управление сценами**

* Главное меню с кнопкой Start
* При нажатии — переход на сцену со спавном целей
* Escape — возвращение в меню.
