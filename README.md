# Модуль 5. Архитектура. Часть 1
## Задание 1
Проект представляет собой простой прототип арены на Unity.

Враги и предметы спавнятся через равные промежутки времени.
Все игровые настройки (тайминги спавна, скорость врагов, целевой счёт) вынесены в ScriptableObject конфиги.

У врагов две стратегии поведения, которые выбираются в конфиге:

* патрулирование по точкам
* следование за игроком при приближении

Игрок получает очки за подбор предметов.
При достижении целевого количества очков на экране появляется сообщение о победе (спавн врагов и предметов останавливается).

По нажатию кнопки «Показать историю» в консоль выводится история событий текущей игровой сессии.
