# Практика по Модулю 4. Продвинутый C#. Часть 1

## 🎮 Задание 2

В проекте используется файл **`news.json`**, который хранится в папке **StreamingAssets** и содержит список новостей.

### Данные:
* Данные загружаются асинхронно через NewsLoader.
* Если JSON некорректен, пустой или файл отсутствует — статус выводит сообщение об ошибке.
* Показ новостей происходит через корутину, выводя по одной новости каждые 2 секунды.

### В интерфейсе есть:
* **ScrollView**, в котором отображаются сами новости.
* **Строка статуса**, где показываются сообщения о загрузке и возможные ошибки.
* **Кнопка “Обновить”**, позволяющая перезагрузить новости из файла.
* **Спиннер загрузки**, который показывается, пока выполняется async-загрузка.

### Также добавлены **конфиги настроек**:

* Конфиг отображения новостей (цвета каждого раздела новости).
* Конфиг отображения статуса (цвета сообщений об ошибках, предупреждениях, успешной загрузке).
